# In-game settings

For **0.9.20**, open the gear on the WNX Tracker while in the hangar.
The Tracker also offers four tabs for its display modes. Use the gear for
the remaining WNX settings, including loading, battle panels, Tab, Alt
and vehicle markers. The language selector offers English and Ukrainian.

- **Apply** saves the draft and keeps the window open.
- **OK** saves the draft and closes the window.
- **Cancel** or **Escape** discards the draft when the window is open.
- **Reset statistics** resets the active account's local Tracker history
  after confirmation. **Restore position** moves the widget to its default
  location. These controls are separate from resetting mod preferences.

The optional modsSettingsApi page is available when a compatible Mod Menu
is installed. The game's built-in Settings no longer contains the Unicum
tab in 0.9.20. The configuration remains under
`mods/configs/unicum/settings.json`; see [Privacy and data use](../PRIVACY.md)
for the local history and caches.

The older native-tab behavior is documented in the
[v0.9.18 release](https://github.com/gmrkinichuk-gif/unicum-wnx-ui/releases/tag/v0.9.18).
